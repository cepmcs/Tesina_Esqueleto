\chapter{Metodología}
\label{ch:metodologia}

En este capítulo se describe la metodología empleada en esta tesina de grado. Se explica el proceso de ajuste de hiperparámetros y evaluación de metaheurísticas multiobjetivo en el reccorido del espacio latente del modelo generativo, seguido por la formulación del problema de diseño de inhibidores dirigidos a la inhibición de la extracción de quimioterapeúticos del interior de la célula tumoral por parte de \gls{mrp1}.

\section{Visión General de la Metodología}
\label{sec:vision_general}

% Explicación del flujo completo: preentrenamiento del VAE, optimización multiobjetivo en espacio latente y evaluación de candidatos.

Se propone un esquema estructurado en dos etapas. La primera abarca el desarrollo, ajuste y evaluación comparativa de un \gls{vae}. La segunda consiste en la exploración de su espacio latente mediante metaheurísticas multiobjetivo para la generación de moléculas. El objetivo de la primera etapa es determinar la configuración con mejor desempeño en la generación molecular y utilizar dicha configuración como base para la posterior búsqueda y optimización de compuestos dirigidos a la diana \gls{mrp1}.

En la primera etapa se entrena un \gls{vae} sobre el benchmark \gls{moses}~\cite{polykovskiy2020molecular}. El propósito del modelo es comprimir la estructura química de los compuestos en un espacio latente continuo. Su evaluación se realiza bajo el protocolo y las métricas estándar de \gls{moses} para seleccionar la mejor combinación de representación molecular, arquitectura e hiperparámetros.

En la segunda etapa se emplean algoritmos metaheurísticos multiobjetivo para explorar el espacio latente continuo del \gls{vae}. Este proceso se divide en dos fases:

\begin{enumerate}
    \item \textbf{Ajuste de hiperparámetros y evaluación en fármacos genéricos:} Se optimizan simultáneamente propiedades fisicoquímicas para comparar el desempeño de los algoritmos y calibrar sus hiperparámetros mediante indicadores químicos y multiobjetivo.
    \item \textbf{Diseño de inhibidores de \gls{mrp1}:} Primero se identifica el sitio de unión del sustrato. Con base en esto, se emplean las mejores configuraciones de los algoritmos para optimizar la afinidad hacia la diana, dirigiendo la búsqueda hacia moléculas con interacciones en ese sitio.
\end{enumerate}

\subsection{Conjuntos de Datos y Preprocesamiento}
\label{subsec:datasets}

Para el entrenamiento del modelo generativo se utiliza el conjunto de datos \gls{moses}~\cite{polykovskiy2020molecular}, obtenido a partir de la colección \textit{Clean Leads} de la base de datos pública ZINC~\cite{irwin2020zinc20}. Este conjunto reúne aproximadamente 1.93 millones de moléculas en formato \gls{smiles} con propiedades de compuestos tipo fármaco, previamente filtradas para descartar estructuras inestables, reactivas o con propiedades farmacológicas desfavorables. Estas moléculas son genéricas y no están dirigidas a ninguna diana biológica en particular. Cuentan con un peso molecular de entre $250$ y $350\text{ Da}$, $\log P \le 3.5$, hasta 7 enlaces rotables, ciclos de no más de 8 átomos y están formadas únicamente por átomos de C, N, O, S, F, Cl, Br e H.

Para los experimentos se utilizan las particiones oficiales del conjunto de datos, utilizando el conjunto de entrenamiento ($\sim$1.58 millones de moléculas) para ajustar el modelo y el conjunto de prueba ($\sim$176 mil moléculas) para evaluar su desempeño.

\subsection{Representaciones Moleculares y Decodificación}
\label{subsec:rep_solucion}

En este trabajo se exploran y comparan dos representaciones lineales: \gls{smiles} y \gls{selfies}. Se utiliza \gls{smiles} por ser el formato estándar del benchmark \gls{moses}, mientras que \gls{selfies} se incorpora para evitar la generación de estructuras sintéticamente inválidas. Comparar ambas permite evaluar el impacto de esta robustez sobre la calidad del espacio latente. En el caso de \gls{smiles}, las cadenas se tokenizan mediante la expresión regular propuesta por Cretu et al.~\cite{cretu2023standardizing}, preservando átomos multicarácter (como $\text{Br}$ y $\text{Cl}$), enlaces, ramas y ciclos como unidades individuales. Para \gls{selfies}, la tokenización se realiza de forma nativa a partir de sus identificadores entre corchetes~\cite{Krenn2019SELFIES}. En ambas representaciones se incorporan los tokens de control de inicio (\texttt{[SOS]}), fin (\texttt{[EOS]}), símbolo desconocido (\texttt{[UNK]}) y relleno (\texttt{[PAD]}) para homogeneizar la longitud de las secuencias en los lotes de entrenamiento. La Figura~\ref{fig:codificacion_tokens} muestra un ejemplo de esta tokenización para una molécula en ambas representaciones.

\input{Figures/codificacion_tokens.tex}

Esta representación en secuencias de tokens sirve como base para el proceso de decodificación, mediante el cual el modelo reconstruye o genera nuevas moléculas a partir del espacio latente. Para ello, la red decodificadora toma un vector latente $\mathbf{z}$ muestreado en el espacio continuo y genera de manera autorregresiva una nueva cadena token a token, iniciando con el delimitador \texttt{[SOS]} hasta emitir \texttt{[EOS]}. Finalmente, la secuencia obtenida se interpreta como una estructura molecular bajo las reglas de la representación empleada (\gls{smiles} o \gls{selfies}).

En esta sección se describe la primera etapa metodológica, orientada a dos objetivos principales: seleccionar la mejor configuración del modelo generativo (\gls{vae}) a través de un espacio de búsqueda por fases, y calibrar los hiperparámetros de las metaheurísticas multiobjetivo al optimizar propiedades generales en su espacio latente.

\subsection{Ajustes de Hiperparámetros del VAE}
\label{subsec:hiperparametros_vae}
\label{subsubsec:hiperparametros_vae}
\label{sec:vae_metodologia}
\label{sec:modelo_generativo}

Con el fin de determinar la configuración con mejor desempeño del \gls{vae}, el espacio de búsqueda de hiperparámetros se estructuró en dos fases secuenciales, totalizando 72 entrenamientos independientes. Se optó por evaluar primero la estructura del autoencoder y posteriormente sus parámetros de optimización, evitando así escalar el tiempo de cómputo de forma desmedida. Así, la primera fase define la representación y la arquitectura base, y la segunda afina la tasa de aprendizaje y el tamaño de lote en las mejores configuraciones:

\begin{itemize}
    \item \textbf{Fase 1 (Estructura base):} Se evaluaron 48 configuraciones combinando la representación molecular (\gls{smiles} y \gls{selfies}), el tipo de celda recurrente (\gls{gru} y \gls{lstm}), la cantidad de capas ocultas (1 y 2), la dimensión latente (64, 128 y 256) y las épocas de entrenamiento (100 y 300). La tasa de aprendizaje y el tamaño de lote se mantuvieron fijos en $1 \times 10^{-3}$ y 128. Las dimensiones latentes se basan en trabajos previos de VAE moleculares~\cite{GBWHLDSA18} para probar diferentes capacidades de representación, y las épocas buscan evaluar si un entrenamiento prolongado mejora los resultados.
    \item \textbf{Fase 2 (Optimización):} Sobre los cuatro modelos representativos con mejor balance de la fase previa, se exploraron dos tasas de aprendizaje ($1 \times 10^{-3}$ y $1 \times 10^{-4}$) y tres tamaños de lote (64, 128 y 192), sumando 24 ejecuciones adicionales. El objetivo fue comprobar si una tasa de aprendizaje más baja ($1 \times 10^{-4}$) permitía un mejor ajuste y evaluar el efecto de variar el tamaño de lote en el entrenamiento.
\end{itemize}

\textbf{Esquema de entrenamiento y regularización.} Todos los modelos se entrenaron utilizando el optimizador Adam~\cite{kingma2014adam}. Para evitar el colapso del espacio latente, se aplicó un aumento gradual del peso de la divergencia KL, inspirado en la implementación \textit{Chemical VAE}~\cite{GBWHLDSA18} y en el benchmark \gls{moses}~\cite{polykovskiy2020molecular}. \subsection{Ajuste de Hiperparámetros de las Metaheurísticas}
\label{subsec:ajuste_metaheuristicas}
\label{sec:optimizacion_multiobjetivo}

Una vez determinado el modelo generativo base, esta subsección aborda la calibración de las metaheurísticas multiobjetivo en su espacio latente. Se presentan los cinco algoritmos evaluados, las funciones objetivo y restricciones químicas consideradas, y el diseño experimental adoptado para ajustar sus parámetros.

\subsubsection{Metaheurísticas Consideradas}
\label{subsec:metaheuristicas}
\label{subsubsec:metaheuristicas}
\label{sec:metaheuristicas}

Se consideran cinco algoritmos metaheurísticos multiobjetivo para la experimentación, todos ellos operando sobre el espacio latente continuo del \gls{vae}:

\textbf{\acrshort{nsga2} (Non-dominated Sorting Genetic Algorithm II).} Es el algoritmo evolutivo multiobjetivo de referencia y se apoya en la profundidad de dominancia. En cada generación ordena la población en frentes sucesivos de no dominancia mediante un procedimiento de ordenamiento rápido. Los empates dentro de un mismo frente se resuelven con la \textit{distancia de apiñamiento} (\textit{crowding distance}), que mide qué tan poblado está el entorno de cada individuo y favorece a los que se encuentran en regiones menos densas. Estos dos mecanismos, junto con una estrategia elitista, le permiten mantener a la vez convergencia y diversidad~\cite{deb2002nsga2}.

\textbf{\acrshort{nsga3} (Non-dominated Sorting Genetic Algorithm III).} Conserva el esquema anterior, pero reemplaza la distancia de apiñamiento por un mecanismo de nichos basado en puntos de referencia distribuidos sobre un hiperplano normalizado. Cada solución se asocia al punto de referencia más cercano y sobreviven primero las soluciones asociadas a los puntos con menos representantes. De esta forma se logra una cobertura uniforme del frente incluso cuando crece el número de objetivos~\cite{deb2014nsga3}.

\textbf{\acrshort{moead} (Multiobjective Evolutionary Algorithm Based on Decomposition).} Descompone el problema multiobjetivo en un conjunto de subproblemas escalares, definidos por vectores de pesos, y los optimiza de forma simultánea. Cada subproblema se resuelve usando solo la información de sus subproblemas vecinos. La distribución de las soluciones sobre el frente depende de cómo se distribuyan los vectores de pesos, y no de un mecanismo explícito de preservación de la diversidad~\cite{zhang2007moead}.

\textbf{\acrshort{cmopso} (Competitive Mechanism Based Multi-objective Particle Swarm Optimizer).} Pertenece a la familia de la optimización por enjambre de partículas. El rendimiento de los optimizadores convencionales de esta familia depende en gran medida de las mejores soluciones globales y personales guardadas en un archivo externo. CMOPSO, en cambio, selecciona en cada generación un conjunto de partículas élite del propio enjambre, según el frente de no dominancia y la distancia de apiñamiento, y actualiza cada partícula mediante una competencia por pares entre dos élites elegidas al azar: gana la que forma el ángulo menor con la partícula~\cite{zhang2018competitive}.

\textbf{\acrshort{agemoea} (Adaptive Geometry Estimation Based MOEA).} Parte de que el desempeño de los algoritmos multiobjetivo depende de la geometría del frente de Pareto, que puede ser una hipersuperficie euclídea, esférica o hiperbólica. Sobre el esquema de \acrshort{nsga2}, reemplaza la distancia de apiñamiento por un puntaje de supervivencia que combina diversidad y proximidad mediante una norma $L_p$ adaptativa. La estimación de dicha geometría se realiza mediante un procedimiento de complejidad $O(n \times N)$, donde $n$ es el número de objetivos y $N$ el tamaño de la población. De este modo mantiene un rendimiento competitivo ante frentes de geometrías diversas, donde los algoritmos que suponen una geometría fija tienden a degradarse~\cite{panichella2019adaptive}.

\subsubsection{Funciones Objetivo y Restricciones}
\label{subsec:fo_genericos}
\label{subsubsec:fo_genericos}

En este apartado se describen las funciones objetivo y la restricción estructural empleadas para guiar la búsqueda de los algoritmos en el espacio latente continuo del \gls{vae}, todas ellas calculadas con RDKit~\cite{landrum2026rdkit}, una librería de quimioinformática utilizada para el análisis y cálculo de descriptores moleculares:

\begin{itemize}
    \item \textbf{\gls{qed} (\textit{Quantitative Estimate of Drug-likeness})~\cite{Bickerton2012QED}:} [Problema de maximización] Cuantifica la probabilidad de que una molécula presente propiedades farmacológicas adecuadas. Asigna una puntuación continua entre $0$ y $1$ mediante funciones de deseabilidad derivadas de múltiples descriptores fisicoquímicos.
    \item \textbf{\gls{sas} (\textit{Synthetic Accessibility Score})~\cite{Ertl2009SAScore}:} [Problema de minimización] Evalúa la dificultad teórica para sintetizar la molécula en un laboratorio químico. Asigna una puntuación continua en el rango $[1, 10]$, donde valores menores indican mayor accesibilidad sintética.
\end{itemize}

Para alejar la búsqueda de estructuras planas, se considera que una mayor proporción de carbonos saturados suele favorecer la solubilidad acuosa~\cite{Lovering2009Flatland} y disminuir tanto la promiscuidad biológica como la inhibición de citocromos CYP450~\cite{Lovering2013Flatland2}.

\textbf{Restricción de complejidad estructural.} La fracción de carbonos con hibridación $sp^3$ ($F_{\text{sp3}}$) se define como:
\begin{equation}
    F_{\text{sp3}} = \frac{\text{número de carbonos } sp^3}{\text{número total de carbonos}}
\end{equation}

Esta propiedad se aplica como restricción de factibilidad ($F_{\text{sp3}} \ge 0.30$). Este límite coincide con los promedios observados en etapas iniciales de descubrimiento ($\sim 0.32\text{--}0.36$), intervalo a partir del cual la promiscuidad comienza a descender de forma sostenida~\cite{Lovering2013Flatland2}.

Para gestionar esta restricción, los algoritmos emplean el criterio de dominancia restringida~\cite{deb2002nsga2}, donde las soluciones factibles siempre dominan a las infactibles, y entre infactibles se prioriza la de menor violación. Asimismo, si un vector latente decodifica en una estructura químicamente inválida según RDKit, se le asigna la máxima penalización en ambos objetivos y en la violación de restricción, forzando a la búsqueda a mantenerse dentro de las regiones viables del espacio latente.

\subsubsection{Operadores e Hiperparámetros de los Algoritmos Genéticos}
\label{subsubsec:hp_ga}

Los cuatro algoritmos genéticos (\acrshort{nsga2}, \acrshort{nsga3}, \acrshort{moead} y \acrshort{agemoea}) comparten el mismo espacio de hiperparámetros, definido por el tipo de operador de cruce y mutación. Se evalúan los siguientes operadores:

\begin{itemize}
    \item \textbf{Cruce Binario Simulado (SBX)~\cite{deb1995sbx}:} Genera dos hijos a partir de dos padres imitando el comportamiento del cruce de un punto en codificación binaria, pero adaptado a variables reales.
    \item \textbf{Cruce Centrado en Padres (PCX)~\cite{deb2002pcx}:} Genera cada hijo cerca del centroide de los padres seleccionados, desplazándolo ligeramente hacia uno de ellos y añadiendo una pequeña perturbación aleatoria en las demás direcciones.
    \item \textbf{Mutación Polinomial (PM)~\cite{deb1996polynomial}:} Perturba cada variable del individuo a partir de una distribución polinomial.
    \item \textbf{Mutación Gaussiana~\cite{back1993gaussian}:} Añade a cada variable un ruido aleatorio extraído de una distribución normal.
\end{itemize}

\subsubsection{Etapas del Protocolo Experimental}
\label{subsubsec:etapas_protocolo}

El estudio comprende cuatro etapas. Se utiliza el hipervolumen como criterio principal para elegir las mejores configuraciones porque evalúa a la vez la convergencia y la diversidad de las soluciones, sin requerir un frente de referencia previo:

\begin{enumerate}
    \item \textbf{Estudio de hiperparámetros:} Se ejecutan 20 semillas independientes por configuración ($(108 \times 4 + 81) \times 20 = 10\,260$ ejecuciones en total). Para cada combinación de operadores (\texttt{pcx/pm}, \texttt{pcx/gauss}, \texttt{sbx/pm}, \texttt{sbx/gauss}) en los algoritmos genéticos y para \acrshort{cmopso}, se selecciona la mejor configuración interna basándose en el menor rango medio de hipervolumen entre las 20 semillas.
    \item \textbf{Comparativa de operadores genéticos:} Fijando la mejor configuración de cada combinación de operadores, se analizan las cuatro variantes por algoritmo para evaluar el impacto del cruce y la mutación mediante pruebas estadísticas sobre el hipervolumen e indicadores químicos.
    \item \textbf{Comparación final frente a \textit{baselines}:} Se toman las mejores configuraciones globales de los cinco algoritmos y se comparan entre sí y contra cuatro métodos de referencia (Aleatorio, Cribado MOSES, Escalador y GA de suma ponderada) sobre todos los indicadores multiobjetivo y químicos.
    \item \textbf{Análisis del frente conjunto global y moléculas representativas:} Evaluación del frente no dominado conjunto obtenido a partir de las combinaciones de operadores (incorporando las familias de cruce PCX y SBX de todos los algoritmos genéticos y \acrshort{cmopso}) y análisis de las moléculas representativas.
\end{enumerate}

En total, el estudio comprende $10\,260$ ejecuciones independientes, cada una con un número fijo de 100\,000 evaluaciones.

\section{FASE 2: Diseño de Inhibidores de la Proteína MRP1}
\label{sec:fase2_mrp1}
\label{sec:diseno_inhibidores_mrp1}

Una vez seleccionada la mejor configuración de las metaheurísticas, se aplica el esquema tomando como diana a \gls{mrp1}, con el objetivo específico de inhibir la expulsión del irinotecán del espacio intracelular. En esta sección se describe la preparación de la proteína y la identificación de su sitio de unión, la formulación de las funciones objetivo junto con el acoplamiento molecular, y el protocolo de generación de los candidatos.

\subsection{Preparación de la Proteína y Sitio de Unión}
\label{subsec:prep_proteina}

El procedimiento propuesto se organiza en una serie de etapas consecutivas que permiten definir las condiciones necesarias para evaluar las moléculas generadas. Como se muestra en la Figura~\ref{fig:pipeline_preparacion_mrp1}, las primeras etapas se centran en la selección y preparación del receptor, seguidas por la identificación y caracterización del sitio de unión mediante simulaciones con un ligando de referencia. Esta información se utiliza posteriormente para delimitar la región de búsqueda que se empleará en los experimentos de docking. Por último, se preparan las estructuras tridimensionales de las moléculas candidatas para llevar a cabo dicha evaluación.

\input{Figures/pipeline_preparacion_mrp1.tex}

\textbf{Estructura de referencia.} Como no existen estructuras en el \textit{Protein Data Bank} que contengan los quimioterápicos de interés unidos a \gls{mrp1}, se recurre a la literatura. Se utiliza la estructura 8VUX, correspondiente a ABCC1 (\gls{mrp1}) humano cocristalizado con \gls{cgamp} y determinada por microscopía crioelectrónica con una resolución de 3.54~Å (ángstroms, unidad de medida de distancias a escala atómica equivalente a $0.1\text{ nm}$)~\cite{shinde2025structures}. El \gls{cgamp} es un nucleótido cíclico mensajero que desempeña un papel clave en la inmunidad innata y en la respuesta contra infecciones y tumores. Si bien el \gls{cgamp} no es un quimioterapéutico, los autores del trabajo que reporta la estructura señalan que el sitio donde se une es el sitio de unión del sustrato de \gls{mrp1}, localizado en el dominio transmembrana TMD2~\cite{shinde2025structures}.

\textbf{Preparación del receptor.} Puesto que la proteína en la estructura 8VUX se encuentra como un homodímero, los experimentos de esta tesina se centran únicamente en la cadena B como receptor. Sobre esta se eliminan el \gls{cgamp}, el hemisuccinato de colesterol y las moléculas de agua. Posteriormente se añaden los átomos de hidrógeno, se asignan los estados de protonación estándar de cada residuo y las cargas parciales, y se genera el archivo en formato PDBQT con Meeko~\cite{santosmartins2025meeko}. El receptor resultante comprende 1005 residuos y 9587 átomos, de los cuales 1658 son hidrógenos polares.

\textbf{Identificación del sitio de unión.} Se procede a identificar los sitios drogables de 8VUX posteriormente a la separación de la proteína del ligando, con énfasis en TMD2 por su asociación con el sitio de unión del sustrato. Para ello se utiliza FPocketWeb~\cite{kochnev2022fpocketweb}, que arrojó como resultado una cavidad drogable en TMD2, el bolsillo número 78, con una drogabilidad reportada de 0.738 (probabilidad de drogabilidad elevada), y que además coincide con el sitio de unión del \gls{cgamp}. Como resultado, se selecciona el bolsillo 78 como sitio de unión probable de los quimioterápicos. Los demás bolsillos con elevada drogabilidad no se consideran porque corresponden a las cavidades donde se une el ATP para accionar el mecanismo de extracción de \gls{mrp1}.

\textbf{Docking ciego y elección de los aminoácidos flexibles.} Como no existe una estructura que cocristalice \gls{mrp1} con los quimioterápicos de interés, los aminoácidos relevantes se identifican de manera computacional. Para ello se utiliza AutoDock Vina~\cite{trott2010vina,eberhardt2021vina} en un docking ciego sobre el bolsillo 78, con el irinotecán como ligando de referencia (PubChem, CID 60838), con el objetivo de determinar las poses más probables y los aminoácidos con los que más interacciona. Vina se configuró con un centro en $(164.6835,\ 130.2140,\ 120.1165)$~Å y una caja de $29.2 \times 35.6 \times 35.0$~Å, una exhaustividad de 32 y la generación de 100 poses.

Para el irinotecán se obtuvo una puntuación de docking de $-12.060$~kcal/mol y 5 poses. Posteriormente se analizaron los aminoácidos situados a menos de 4~Å del ligando, con el fin de caracterizar las interacciones potenciales en la región de unión; los resultados se resumen en la Tabla~\ref{tab:frecuencia_residuos}.

\subsection{Funciones Objetivo y Acoplamiento Molecular}
\label{subsec:fo_mrp1}

Para el diseño dirigido hacia \gls{mrp1} se añade la energía de unión como tercer objetivo junto a \gls{qed} y \gls{sas}, con el fin de guiar la búsqueda hacia la interacción con la diana objetivo. De este modo, se optimizan simultáneamente sobre el espacio latente del \gls{vae}:

\begin{itemize}
    \item \textbf{Energía de unión:} [Minimizar] Energía libre de afinidad de unión de la molécula con \gls{mrp1}, estimada mediante acoplamiento molecular con la función de puntuación de AutoDock Vina~\cite{trott2010vina}. Se utiliza su implementación en \gls{gpu}, Uni-Dock~\cite{yu2023unidock}, que reproduce dicha función de puntuación y evalúa un lote de moléculas en paralelo.
    \item \textbf{\gls{qed}:} [Maximizar] Definida en la sección~\ref{subsec:fo_genericos}.
    \item \textbf{\gls{sas}:} [Minimizar] Definida en la sección~\ref{subsec:fo_genericos}.
\end{itemize}

Cada molécula se acopla con el receptor rígido descrito en la subsección~\ref{subsec:prep_proteina}, dentro de la caja de docking de los experimentos de diseño, con un modo de búsqueda balanceado y una semilla fija, y se toma la energía de la mejor pose como valor del objetivo.

Se mantiene la restricción de complejidad estructural $F_{\text{sp3}} \ge 0.30$ descrita en la sección~\ref{subsec:fo_genericos}, evaluada bajo el mismo criterio de dominancia restringida. Si una molécula no puede prepararse o el acoplamiento no produce una pose, se le asigna la máxima penalización en el objetivo de energía ($+1.0$~kcal/mol). Para el cálculo del hipervolumen, la energía de unión se normaliza entre $-15.0$ y $+1.0$~kcal/mol.

\subsection{Protocolo de Generación de Candidatos}
\label{subsec:protocolo_mrp1}

Se ejecuta la búsqueda dirigida en el espacio latente con las mejores configuraciones seleccionadas en la sección~\ref{sec:farmacos_genericos}, con el mismo total de 100\,000 evaluaciones por ejecución y 20 semillas independientes. El acoplamiento se realiza con el receptor rígido, dentro de la caja de docking definida en la subsección~\ref{subsec:prep_proteina}.

Las moléculas generadas se evalúan en términos de \gls{qed}, \gls{sas}, afinidad, $F_{\text{sp3}}$ y características de unión. Adicionalmente, se evalúan la validez, la unicidad y la diversidad de las moléculas generadas.

\section{Métricas de Evaluación del Rendimiento de los Modelos Considerados}
\label{sec:metricas_evaluacion}

En esta sección se describen las métricas empleadas para evaluar el rendimiento de la metodología. Se presentan las métricas del benchmark \gls{moses} para medir la calidad química, validez y diversidad de las moléculas generadas por el \gls{vae}. Además, se detallan los indicadores multiobjetivo utilizados para comparar la convergencia y distribución de las soluciones obtenidas por las metaheurísticas en el espacio latente.

\subsection{Métricas de Calidad de Generación}
\label{subsec:metricas_moses}
\label{subsec:metricas_calidad_generacion}

Para evaluar y comparar el desempeño de los modelos de \gls{vae} entrenados sobre el conjunto de datos \gls{moses}~\cite{polykovskiy2020molecular}, se emplean las métricas estandarizadas del benchmark:

\textbf{Validez.} Proporción de moléculas generadas que son químicamente viables, verificando que cada estructura respete las leyes de valencia y los criterios básicos de estabilidad química:
\begin{equation}
    \text{Validez} = \frac{\# \text{moléculas válidas}}{\# \text{moléculas generadas}}
\end{equation}

\textbf{Unicidad.} Evalúa la capacidad del modelo para generar estructuras distintas y evitar la repetición de moléculas:
\begin{equation}
    \text{Unicidad} = \frac{\# \text{moléculas generadas únicas}}{\# \text{moléculas generadas}}
\end{equation}

\textbf{Novedad.} Porcentaje de moléculas generadas que aparecen en el conjunto de entrenamiento, evaluando si el modelo generaliza o si memoriza las estructuras conocidas:
\begin{equation}
    \text{Novedad} = 1 - \frac{\# \text{moléculas generadas} \cap \# \text{moléculas de entrenamiento}}{\# \text{moléculas generadas}}
\end{equation}

\textbf{Filtros (\textit{Filters}).} Fracción de moléculas generadas que logran superar los filtros aplicados en el conjunto original, evaluando el cumplimiento de \acrshort{pains} (que descarta compuestos con falsos positivos por interferencia en ensayos biológicos) y \acrshort{mcf} (que elimina fragmentos reactivos, inestables o farmacológicamente desfavorables).

\textbf{Distancia Fréchet ChemNet (\acrshort{fcd}).} Compara la distribución estadística de las moléculas generadas frente a las de referencia utilizando las activaciones de la red neuronal \textit{ChemNet}:
\begin{equation}
    \text{FCD}(G, R) = \|m_G - m_R\|^2 + \text{Tr} \left( C_G + C_R - 2(C_G C_R)^{1/2} \right)
\end{equation}
donde $m$ representa el vector de medias y $C$ la matriz de covarianza de las activaciones para los conjuntos generado ($G$) y real ($R$). Los autores de \gls{moses} destacan a \acrshort{fcd} como una de las métricas centrales del benchmark porque captura de forma conjunta la distribución de propiedades químicas y la relevancia biológica de los compuestos. Una puntuación cercana a cero indica que el modelo replica con precisión el perfil del conjunto de referencia.

\textbf{Diversidad Interna ($\text{IntDiv}$).} Cuantifica la variedad química dentro del conjunto generado para detectar colapso de modos (\textit{mode collapse}):
\begin{equation}
    \text{IntDiv}_p(G) = 1 - \sqrt[p]{\frac{1}{|G^2|} \sum_{m_1, m_2 \in G} T(m_1, m_2)^p}
\end{equation}
donde $T(m_1, m_2)$ evalúa la similitud de Tanimoto entre pares de moléculas generadas. Un resultado cercano a 1 indica alta diversidad estructural.

\textbf{Distancias de Wasserstein-1 (\gls{qed} y \gls{sas}).} Cuantifica la diferencia entre las distribuciones de los datos reales y los generados para la \gls{sas} y la \gls{qed}. Un valor cercano a cero indica que el modelo reproduce con precisión tanto los promedios como la dispersión de estas propiedades en el conjunto de referencia.

\subsection{Indicadores de Rendimiento Multiobjetivo}
\label{subsec:indicadores_multiobjetivo}
\label{sec:indicadores_multiobjetivo}

La evaluación de metaheurísticas multiobjetivo representa un desafío particular ya que el resultado del proceso de optimización no es una única solución, sino un conjunto de soluciones no dominadas. Por lo tanto para evaluar el rendimiento de diferentes algoritmos es necesario comparar conjuntos enteros de soluciones. No existe un estándar único para evaluar estas soluciones los indicadores de calidad o métricas de desempeño se clasifican según sus propiedades y según el objetivo que evalúan~\cite{talbi2009metaheuristics}:

\begin{itemize}
    \item \textbf{Indicadores de convergencia:} Evalúan la eficacia de las soluciones en términos de su cercanía al frente de Pareto óptimo. Ejemplos destacados incluyen la \gls{gd} y la \gls{igd}, que calculan la distancia promedio entre el conjunto aproximado y un conjunto de referencia, y el Indicador $\epsilon$, que determina el factor mínimo de traslación necesario para que una aproximación domine a otra.
    \item \textbf{Indicadores de diversidad:} Miden la uniformidad y extensión de la distribución de las soluciones obtenidas a lo largo del frente. Indicadores como el Espaciado (\textit{Spread}) o la Entropía penalizan los frentes donde las soluciones se agrupan excesivamente en una sola región del espacio de objetivos. Suelen tener un costo computacional mayor que los indicadores de convergencia.
    \item \textbf{Indicadores híbridos:} Evalúan tanto la convergencia como la diversidad del conjunto de soluciones. Tales como el \gls{hv}, un indicador que calcula el volumen del espacio de objetivos que es débilmente dominado por el conjunto de aproximación respecto a un punto de referencia~\cite{talbi2009metaheuristics}.
\end{itemize}

A partir de esta clasificación, los indicadores de rendimiento considerados en el marco metodologico son los siguientes:

\textbf{Hipervolumen (\acrshort{hv}).} Mide el volumen de la región del espacio de objetivos que domina el conjunto de soluciones obtenido, acotada por un punto de referencia (Figura~\ref{fig:indicadores_rendimiento}a). Cuanto mayor es ese volumen, mejor es el conjunto tanto en convergencia como en diversidad, de modo que resume ambos aspectos. Su ventaja práctica es que no exige conocer el frente de Pareto óptimo, sino únicamente el punto de referencia.

\textbf{Distancia generacional invertida modificada (\acrshort{igd}$^+$).} Promedia la distancia que separa a cada punto de un conjunto de referencia de la solución más próxima del conjunto obtenido, contabilizando solo las componentes en las que esa solución es peor (Figura~\ref{fig:indicadores_rendimiento}b). Valores bajos indican que el frente obtenido se aproxima al de referencia.

\textbf{Indicador $\epsilon$ aditivo.} Expresa cuánto habría que desplazar el conjunto obtenido para que llegue a dominar débilmente al de referencia (Figura~\ref{fig:indicadores_rendimiento}c). Cuanto menor es ese desplazamiento, más próximos están ambos frentes, y un valor no positivo significa que el conjunto obtenido ya lo domina. A diferencia de la \acrshort{igd}$^+$, que evalúa la proximidad promedio, este indicador actúa como un criterio de peor caso determinado por la región más desfavorable del frente.

\textbf{Espaciamiento (\textit{Spacing}).} Refleja con qué uniformidad se reparten las soluciones a lo largo del frente (Figura~\ref{fig:indicadores_rendimiento}d), a partir de la dispersión de las distancias entre soluciones vecinas. Valores bajos corresponden a frentes donde las soluciones están espaciadas de manera regular, sin acumulaciones ni huecos.

\textbf{Tamaño del frente de Pareto.} Cuenta las soluciones no dominadas obtenidas, esto es, cuántas alternativas de compromiso distintas llega a ofrecer el algoritmo. Por sí solo no permite juzgar la calidad del frente.

\input{Figures/indicadores_rendimiento.tex}

Los dos indicadores basados en distancias, \acrshort{igd}$^+$ y el indicador $\epsilon$ aditivo, necesitan un conjunto de referencia que aproxime el frente de Pareto óptimo. Como en el diseño de moléculas ese frente no se conoce, dicho conjunto se construye de forma empírica~\cite{liyao2019quality}.

\section{Herramientas y Tecnologías de Implementación}
\label{sec:herramientas_tecnologias}

En esta sección se describen las herramientas y tecnologías empleadas en el entrenamiento y evaluación del modelo generativo, la exploración del espacio latente mediante optimización multiobjetivo y el acoplamiento molecular sobre la proteína \gls{mrp1}. Conda facilitó la gestión de dependencias y entornos virtuales de Python (Versión 3.12.3), utilizándose las siguientes herramientas y librerías principales:

\begin{itemize}
    \item \textbf{PyTorch (Versión 2.12.1):} Utilizado para construir y entrenar las redes neuronales recurrentes (GRU y LSTM) del \gls{vae}.
    \item \textbf{pymoo (Versión 0.6.1.6):} Utilizado para ejecutar los algoritmos de optimización multiobjetivo, sus operadores y las métricas de rendimiento.
    \item \textbf{RDKit (Versión 2026.03.3):} Utilizado para validar estructuras químicas, calcular propiedades moleculares (\gls{qed}, \gls{sas}, $F_{\text{sp3}}$) y generar conformaciones 3D.
    \item \textbf{SELFIES (Versión 2.2.0):} Representación molecular basada en cadenas válidas, empleada como alternativa a \gls{smiles}.
    \item \textbf{MOSES (Versión 0.3.1):} Benchmark para evaluar el modelo generativo y calcular métricas de distribución y calidad química.
    \item \textbf{Uni-Dock (Versión 1.2.0):} Motor de acoplamiento molecular en \gls{gpu}, utilizado para evaluar la afinidad de unión contra \gls{mrp1}.
    \item \textbf{AutoDock Vina (Versión 1.2.7):} Utilizado en el docking ciego y con residuos flexibles para caracterizar el sitio de unión de \gls{mrp1}.
    \item \textbf{Meeko (Versión 0.8.0):} Utilizado para preparar receptores y ligandos en formato PDBQT para el acoplamiento molecular.
    \item \textbf{FPocket:} Utilizado para identificar y evaluar la drogabilidad de cavidades en la estructura de \gls{mrp1}.
\end{itemize}

Además, para el desarrollo, redacción y diseño de esquemas se utilizaron Git para el control de versiones, LaTeX para la composición tipográfica de texto, fórmulas y bibliografía, Visual Studio Code como entorno integrado de desarrollo y TikZ para la creación de los diagramas y esquemas.

En cuanto a los recursos de hardware, los experimentos se llevaron a cabo en el Clúster Toko (FCEN-UNCuyo) sobre nodos con 16 vCPUs y 128~GB de memoria RAM: se empleó una GPU NVIDIA TITAN Xp para el entrenamiento del modelo generativo (\gls{vae}), y nodos equipados con GPU NVIDIA GeForce RTX 4080 para las tareas de optimización multiobjetivo y acoplamiento molecular.
